## P8-C0 — Baseline and budgets

### GPU time in the bench

A locked 60 Hz shows only that the GPU keeps up, not how much it has spare, so the
bench now reports GPU time. `src/app/gpu-timer.ts` wraps each bench frame's render in
an `EXT_disjoint_timer_query_webgl2` query. Results arrive a few frames late. At most
8 queries are in flight, and frames the GPU marked disjoint are dropped. The report
gains `gpuMs`, and the run summary gains `gpuP95Ms`, both absent where the browser has
no timer queries. The GPU-backed headless Chromium that `make bench` uses exposes the
extension.

Tests: `tests/gpu-timer.test.ts` (absent without the extension; results in order once
finished; disjoint frames dropped; bounded in flight; dispose frees everything),
`tests/bench.test.ts` (warm-up GPU times ignored; none reported without the
extension), and `tests/bench-runs.test.ts` (parsed and summarised by median pass).
Gates: lint; 627 unit tests; 53/53 Chromium browser tests (2 workers).
