## P7-C1 — Energy modes

State: done.

- Four modes, each a row of data in the energy rules (now version 2), not a branch in
  the code:

  | Mode       | Deploys without Shift  | Harvests off throttle |
  | ---------- | ---------------------- | --------------------- |
  | Harvest    | nothing                | 120 kW                |
  | Balanced   | 60% of permitted power | no                    |
  | Attack     | 85%                    | no                    |
  | Qualifying | all of it              | no                    |

  Every mode harvests under braking. Holding Shift deploys all permitted power in any
  mode that deploys.

- `E` cycles Balanced → Attack → Qualifying → Harvest. The pause menu has an Energy
  mode choice; it is saved with the other preferences and follows the `E` key. The HUD
  shows the mode's name from the rules.
- **Tests:**
  - energy model: over a scripted lap from half charge, each mode ends with less charge
    and has deployed more than the one before it, and none passes the lap's recharge
    limit; Qualifying deploys the permitted power without Shift; rules missing a mode
    or with a share over 1 are rejected;
  - session: the cycle order, and a chosen mode surviving a retune;
  - preferences: default, remembered, unknown values ignored;
  - browser: `E` steps through all four; the menu choice applies and survives a
    reload.
- Found while testing: the menu's select first took the id `energy`, which the HUD's
  energy block already had, and the page stopped loading. It is `energy-select`.
