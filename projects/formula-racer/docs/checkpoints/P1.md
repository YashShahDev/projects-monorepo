## P1-C1 — Browser bundle and static delivery

State: done. Requires P0-C3 (`d8f8b38`).

Work: `src/index.html` entrypoint; Bun dev server (`tools/dev.ts`, HTML import plus
`public/` files); production `Bun.build` to `dist/` with `NODE_ENV` defined as
production and `public/` copied (collisions fail the build); `tools/serve-dist.ts`
static server with optional base path; validated probe-scene JSON asset fetched
relative to `document.baseURI`.

Findings: Bun emits `./`-relative bundle URLs from an HTML entrypoint, so no
`publicPath` is needed for subpath hosting. Without an explicit `define`, Bun leaves
`process.env.NODE_ENV` unresolved in the production bundle (development-only code
survives); the dev server resolves it to `development`.

Evidence: `make test` 35 pass (static path resolution incl. encoded traversal,
content validation, build output URLs and copied assets). `make lint` passes with
separate tool and browser (`src/tsconfig.json`, DOM lib) type checks. Headless
Chromium loaded the probe asset with no console errors from dev (`/`), production
root and production under `/games/formula-racer` (308 to trailing slash). A
root-relative asset request against the subpath server returns 404 as expected.
Automated browser coverage of these paths is P1-C3.

## P1-C2 — Rendering and WASM

State: done. Requires P1-C1 (`2c619ed`).

Work: `src/simulation/probe-world.ts` hides Rapier behind a plain-pose interface,
initializes WASM once (retry allowed after failure) and fails clearly on use after
dispose. `src/rendering/probe-view.ts` draws the probe scene with Three.js on a
caller-provided WebGL2 context. `src/app/probe-app.ts` stages startup with labelled
failures (WebGL2 absent, content, WASM, renderer), shows a Reload alert, handles
context loss and frame exceptions, disposes on non-persisted `pagehide`, and records
`performance.measure("formula-racer:startup")` at the first frame. Development builds
expose pause/step/state/dispose at `window.__formulaRacerTest`; the production build
fails if that name appears in any script. Physics steps once per displayed frame
until P2-C1 adds the fixed-rate accumulator.

Evidence: `make test` 44 pass, including g·t²/2 free fall, rest at the ground surface,
identical repeated trajectories, scene-provided gravity, independent worlds and
disposal. `make lint` passes; simulation/content modules type-check without DOM.
Headless Chromium 153 and Firefox 155, dev and production under
`/games/formula-racer/`, rendered the ground and box with no page errors or console
errors. Dev hook stepping settled the box at y = 0.49993 m; production had no hook.
Chromium printed "GPU stall due to ReadPixels" driver warnings only during a
screenshot readback in software GL.

Measurements (headless software GL, not hardware; startup = navigation to first frame,
single runs): Chromium 197 ms prod / 222 ms dev; Firefox 131 ms prod / 312 ms dev.
Production script 4,878,615 bytes raw, 1,787,505 gzip -9, 1,307,750 brotli. Rapier's
WASM alone is 3,082,103 bytes (1,168,722 gzip), inlined as base64 by the compat
package. Separate `.wasm` delivery would save roughly 1 MB raw of base64 overhead and
decode time; per ADR-001 that decision waits for a hardware startup measurement.
